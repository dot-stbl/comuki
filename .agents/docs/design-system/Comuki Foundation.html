Foundation — fix this first, it permeates everything

Пульт управления роем агентов. Статус читается формой-иконой — без чтения текста.

Что это

Наблюдательный интерфейс под нодетерминированный рой — ближе к Grafana / Linear / Temporal, чем к CRM. Плотный, информационный, на долгий просмотр.

Характер

Монохром + акцент. Нейтральная шкала плюс один слейт-синий акцент на действиях и danger-красный на сбоях. Моно для машинного, иконы вместо текста. Спокойно, воздушно, премиально-сдержанно.

Дифференциатор

У каждого статуса — своя икона, а не цвет. Состояние роя видно периферийным зрением и не теряется при дальтонизме и в монохроме.

01

Status semantics

Монохром. Несёт форма-икона; значение помогает (running ярче, queued тусклее). Единственный цвет в статусах — danger-красный на failed.
Периферийный читаемый ряд — только иконы, без цвета. Различимы формой.

Монохром: нейтральная шкала + два действующих цвета — accent (действия) и danger (сбои). Глубина через surface и border, не тени.

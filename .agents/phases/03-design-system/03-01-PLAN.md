# Plan 03-01 — Testing infrastructure

## Goal

Поднять полную test-инфраструктуру, чтобы каждая последующая фаза (Slice 0 → MVP) могла писать unit/integration/component/a11y/E2E-тесты по единому конвенциональному стеку, а CI ловил регрессии на каждом коммите. Это **load-bearing** перед любым runtime: без тестов Slice 0 не имеет защитной сетки.

После завершения: `dotnet test`, `bun run test`, `bun run test:e2e`, `bun run build-storybook` все зелёные локально, два новых GitLab CI job-а (`test-backend`, `test-frontend`) с coverage artifacts. Coverage gate 70% на обеих сторонах.

## Tasks

1. **Add test packages to `Directory.Packages.props`**: `xunit.v3`, `Shouldly`, `NSubstitute`, `Testcontainers.PostgreSql`, `Respawn`, `Bogus`, `coverlet.collector` (BE).
2. **Create `tests/Comuki.Platform.Architecture.Tests/Comuki.Platform.Architecture.Tests.csproj`** with NetArchTest + xUnit v3 + Shouldly. Add to `comuki.slnx` under `tests/` solution folder.
3. **Write first architecture test** in `tests/Comuki.Platform.Architecture.Tests/LayerDependencyTests.cs` — assert that `Comuki.Platform.Api.Public` does not reference `Comuki.Platform.Database.Runs` directly (forces going through Orchestration/Contracts). Plus 2 more starter tests per `PROJECT-STRUCTURE.md § 9`.
4. **Create `tests/Acme.Shop.Testing/`** (shared test infra project, NOT a test project itself — `IsTestProject=true` omitted) with Testcontainers + Respawn + Bogus base fixtures. Add to `comuki.slnx`.
5. **Wire `Directory.Build.props`**: add `<IsTestProject>` and `<CollectCoverage>` conditionals for `tests/**/*.csproj`. Add `<Threshold>70</Threshold>` + `<ThresholdType>line</ThresholdType>`.
6. **Add `dotnet test comuki.slnx` smoke**: create `tests/Comuki.Platform.Orchestration.Unit.Lease/` placeholder with one trivial `[Fact]` to prove the wiring works.
7. **Add `bun add -d vitest @vitest/ui @testing-library/react @testing-library/jest-dom jsdom @testing-library/user-event`** to `dashboard/`.
8. **Create `dashboard/vitest.config.ts`** with `jsdom` environment, `@/` path alias, `setup.ts` for jest-dom matchers, and `coverage` config (v8 provider, 70% threshold, exclude `**/*.stories.ts`, `src/main.tsx`).
9. **Add `bun run test` and `bun run test:coverage` scripts** to `dashboard/package.json`.
10. **Add first FE unit test** at `dashboard/src/lib/utils.test.ts` for the `cn()` helper (proves vitest is wired).
11. **Add `@storybook/addon-vitest`, `@storybook/addon-a11y`, `@storybook/test`** to `dashboard/` devDeps. Wire into `.storybook/main.ts` addons list and `.storybook/preview.ts` parameters.
12. **Add `bunx playwright install` config** — create `dashboard/playwright.config.ts` with `webServer: { command: "bun run preview", port: 4173 }`. Add `bun add -d @playwright/test`.
13. **Add `bun run test:e2e` script** and first smoke test at `dashboard/e2e/landing.spec.ts` that boots the landing page and asserts `h1` contains "Comuki".
14. **Update `.gitlab-ci.yml`**: add `test-backend` and `test-frontend` jobs after the existing `build-*` jobs. Both run tests + emit cobertura coverage artifacts. Reuse `dotnet/sdk:10.0` image with `bun` in `before_script`.
15. **Commit**: split into 2 commits — (a) test infra setup with passing tests, (b) CI jobs added.

## Acceptance criteria

- `dotnet test comuki.slnx -c Debug --nologo` exits 0 (0 errors, 0 warnings), runs all BE tests including architecture tests.
- `cd dashboard && bun run test` exits 0, runs vitest with coverage at ≥70% line.
- `cd dashboard && bun run test:e2e` exits 0, smoke test passes against `bun run preview`.
- `cd dashboard && bun run build-storybook` exits 0 (still works after addon install).
- `tests/Comuki.Platform.Architecture.Tests/` is NOT picked up by `dotnet test` (it's a `*.Tests` project but its tests verify layer rules, not business logic — verify it's actually run).
- `tests/Acme.Shop.Testing/` builds but has no `[Fact]` methods (it's a library).
- `.gitlab-ci.yml` contains both `test-backend` and `test-frontend` jobs (grep for both).
- Coverage threshold 70% enforced — temporarily drop a project's coverage to 50%, run `dotnet test`, must fail with threshold error.

# Plan 03-02 — Design tokens

## Goal

Заменить дефолтный shadcn-mauve на **Comuki-палитру** (slate-blue + cool-black) во всех CSS-переменных, переключить шрифт с Geist Mono Variable на **IBM Plex Mono** (per `.agents/docs/design-system/Comuki Design System.md` § 2), добавить **status tokens** (`--st-running`, `--st-success`, `--st-failed`, `--st-waiting`, `--st-queued`, `--st-escalated`) с раздельными hex для dark/light, обновить `--radius: 0.375rem`, обновить Storybook backgrounds и `components.json` baseColor, провалидировать визуально против `Comuki Dashboard.html` reference.

После завершения: build green, dashboard `/` route визуально матчит Comuki Dashboard.html по палитре и типографике, theme-provider работает (dark/light/system), Storybook backgrounds соответствуют.

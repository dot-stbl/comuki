# Plan 03-03 — Stories + 3 custom Comuki components

## Goal

Создать **Storybook stories для всех 55 shadcn-компонентов** в `dashboard/src/components/ui/` (каждый с 6+ states per `frontend-construct-rules.md` § 2: Default, Loading, Disabled, Error, Empty, WithLongText) плюс **3 кастомных Comuki-компонента** с собственными stories:

- `StatusBadge` — пилюля со статусом (`<StatusBadge status="running" />`), цвет из `--st-*` токенов (поэтому **depends on 03-02**), `running` пульсирует, иконка-семантика из lucide
- `RunIdChip` — моно-чип с run-id, copy-to-clipboard через sonner toast
- `ModeToggle` — sun/moon/system theme switcher, использует `useTheme()` из `theme-provider.tsx`

Подключить `@storybook/addon-vitest` (browser-mode component tests) + `@storybook/addon-a11y` (axe). Definition of Done per `frontend-construct-rules.md` § 5: cva variants, no arbitrary values, axe green, visual regression green (or baseline осознанно обновлён).

## Tasks

1. **Install Storybook addons**: `cd dashboard && bun add -d @storybook/addon-vitest @storybook/addon-a11y @storybook/test`. Verify versions compatible with Storybook 8.6.
2. **Wire addons in `dashboard/.storybook/main.ts`**: add `addon-vitest` and `addon-a11y` to `addons` array (after `addon-essentials`).
3. **Wire a11y parameters in `dashboard/.storybook/preview.ts`**: add `parameters: { a11y: { config: { rules: [{ id: 'color-contrast', enabled: true }] } } }`.
4. **Create `dashboard/src/components/ui/status-badge.tsx`**:
   - Props: `status: 'running' | 'success' | 'failed' | 'waiting' | 'queued' | 'escalated'`, `className?: string`, optional `children?: ReactNode` for label override
   - Variant via `cva` with size variants `--sm`, `--md`
   - Color via Tailwind classes: `bg-st-running/15 text-st-running` (using `--st-*` tokens mapped in 03-02)
   - Icon: lucide `Activity`, `Check`, `X`, `Clock`, `Circle`, `ChevronsUp` (matching design-spec § 3 icon column)
   - `running` variant: `animate-pulse` (with `@media (prefers-reduced-motion: no-preference)` guard)
   - Use `cva` + `cn()` per `frontend-construct-rules.md` § 1 "Components"
5. **Create `dashboard/src/components/ui/run-id-chip.tsx`**:
   - Props: `id: string`, `className?: string`
   - Mono font via `font-mono`, `text-xs`, `text-muted-foreground`
   - Truncate long ids (>12 chars) with `truncate` Tailwind class
   - Click → `navigator.clipboard.writeText(id)` + `toast.success('Copied', { description: id })` via `sonner`
   - Copy icon (lucide) + "Copied" state on success (icon swap to `Check`)
6. **Create `dashboard/src/components/ui/mode-toggle.tsx`**:
   - Use `useTheme()` from `@/components/theme-provider` (NOT from `next-themes` — that's for sonner only)
   - `DropdownMenu` (shadcn) with three items: Light, Dark, System
   - Icon: lucide `Sun`, `Moon`, `Monitor` based on current `theme`
   - Trigger button: `Button variant="ghost" size="icon"`
7. **Create `dashboard/src/stories/` stories for all 55 shadcn components** — one file per component, e.g. `button.stories.ts`, `card.stories.ts`, etc. Each story has these states (per `frontend-construct-rules.md` § 2):
   - `Default` — canonical usage
   - `Loading` — skeleton/spinner state if applicable, else omit
   - `Disabled` — `disabled` prop applied
   - `Error` — error variant/message if applicable, else omit
   - `Empty` — empty content (only for components that hold data)
   - `WithLongText` — overflow test (use `lorem ipsum` or 200+ chars)
   - Interactive components (Button, Dialog, etc.): add `play()` function
8. **Create stories for the 3 custom components**: `dashboard/src/stories/status-badge.stories.ts`, `run-id-chip.stories.ts`, `mode-toggle.stories.ts` — each with 6+ states per same convention.
9. **Verify storybook build**: `cd dashboard && bun run build-storybook` — exit 0.
10. **Verify component tests**: `cd dashboard && bun run test` (addon-vitest runs in browser mode via Playwright) — exit 0, 0 axe violations.
11. **Manual screenshot review** of at least 5 stories (Button, Card, Dialog, StatusBadge, ModeToggle) in light AND dark themes, verify tokens from 3.2 are applied.
12. **Commit**: split into 3 commits: (a) 3 custom components + their stories, (b) 55 shadcn stories, (c) addon wiring + green CI.

## Acceptance criteria

- 3 files exist: `dashboard/src/components/ui/status-badge.tsx`, `run-id-chip.tsx`, `mode-toggle.tsx` — each <200 lines, uses `cva` + `cn()`, no arbitrary Tailwind values.
- `dashboard/src/stories/*.stories.ts` contains ≥58 files (55 shadcn + 3 custom).
- Each story file has ≥6 exports matching the 6 states per `frontend-construct-rules.md` § 2.
- `dashboard/.storybook/main.ts` addons array contains `@storybook/addon-vitest` and `@storybook/addon-a11y`.
- `cd dashboard && bun run build-storybook` exits 0.
- `cd dashboard && bun run test` exits 0, 0 axe violations across all stories.
- `mode-toggle.tsx` imports `useTheme` from `@/components/theme-provider` (NOT from `next-themes`).
- `run-id-chip.tsx` uses sonner for the copy confirmation (not custom toast UI).
- `status-badge.tsx` `running` variant includes `prefers-reduced-motion` guard on the pulse animation.
- All stories render in both light and dark themes (verified by switching theme in Storybook toolbar).
- Definition of Done per `frontend-construct-rules.md` § 5: cva variants ✓, no arbitrary values ✓, all states ✓, component tests + a11y green ✓, build-storybook green ✓.

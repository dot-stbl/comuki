# BLOCKING CONSTRAINTS — Read Before Anything Else

> Discovered through actual failure during this session.

- [x] **NuGet packages must match target framework major.** `Microsoft.AspNetCore.OpenApi 9.x` + `Microsoft.Extensions.ApiDescription.Server 9.x` on `net10.0` runtime BOTH fail — first with `GetDocumentCommandWorker..cctor` static constructor errors on assembly resolve, second with missing `GetDocument.Insider.dll` under `net10.0/`. Pin to 10.0.0 minimum. (Fixed in commit `e3d2413`.)
- [x] **`Microsoft.Extensions.ApiDescription.Server --file-name` takes base name, not filename.** Regex `[A-Za-z0-9_-]+` rejects dots. `--file-name openapi.v1.json` errors with "FileName format invalid". Use `--file-name openapi-v1`, generator appends `.json`. (Fixed in commit `472f049`.)
- [x] **Kubb 5.0.0-beta plugins silently no-op against `@kubb/core` 4.x.** `Building 0 schemas` / `plugin-ts completed in 0ms` with no output. Align all `@kubb/*` to 4.37.x. (Fixed in commit `34200f2`.)
- [x] **`ajv-draft-04@1.0.0` requires `ajv@7` (not 8).** Old path `ajv/dist/core` was removed in ajv 8.x. Use `bun add -D ajv@^7`. (Fixed in commit `34200f2`.)
- [x] **.NET 10 analyzer default `caller-argument-expression` style is `false`.** When the user lands a doc, the editor will add `parameterName:` for `ThrowIfNull` etc. Don't fight it.

_All five are committed in history; not a future risk unless someone re-bumps._

## Critical Anti-Patterns (do NOT repeat these)
<!-- Lessons from this session that the resuming agent must respect -->
- **Don't promise to "add" something already there.** soly auto-applied an `ANALYZERS.md` rule that wired Roslynator + Meziantou to `Directory.Build.props` while I was in the middle of work. Don't waste a turn "fixing" what's already wired — read STATE.md decisions before acting.
- **Don't pre-bump analyzer/analyzer-dependency majors on speculation.** Both Meziantou (3.0.98) and Roslynator (4.15.0) ARE the latest on nuget. `dotnet package search` showed only 1.x (local cache); the live `restore` errored with `Ближайшая версия: 4.15.0` confirming 4.15.0 is latest. Use `dotnet restore` after a props bump to verify, not `dotnet package search`.
- **Don't use `dotnet add package` for analyzers listed in `Directory.Build.props`.** It adds a local `PackageReference` to the calling `.csproj`, which is the opposite of "global analyzer". Update `Directory.Packages.props` directly.
- **Don't commit `src/api/.kubb/`** — Kubb debug state. Already in `.gitignore`.
- **Don't commit `**/openapi-*.json`** — build-time OpenAPI spec, regenerated by every `dotnet build`.

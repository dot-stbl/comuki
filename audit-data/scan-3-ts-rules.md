## 3.6 Recommended test/style additions

1. **`useEffect` smell guard** — extend `dashboard/` lint to disallow
   `useEffect` containing `fetch(` or kubb-client method calls (the FE
   equivalent of "use TanStack Query for data").
2. **No `any` in production code** — the current ESLint config already
   bans `@typescript-eslint/no-explicit-any` with `warn` (the
   `eslint-disable-next-line` overrides should remain for test-only
   escape hatches). Consider tightening test-file bans separately.
3. **`console.*` ban in `src/**/*.{ts,tsx}`** — the
   `eslint-plugin-no-console` rule with `allow: ['warn', 'error']`
   would catch any future accidental `console.log` in production.
4. **TODO/FIXME ban in `src/**/*.{ts,tsx}`** — a custom ESLint rule
   or a simple `bun run lint`-precommit grep would keep the
   `// TODO` discipline.

Net: dashboard FE **is clean.** Codebase has 1525 tests passing,
typecheck + lint pass, no obvious ban violations.

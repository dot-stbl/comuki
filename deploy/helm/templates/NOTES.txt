  {{- if .Values.dashboard.enabled }}
     kubectl port-forward svc/{{ include "comuki.fullname" . }}-dashboard 8080:80
     open {{ .Values.publicUrl }}
  {{- else }}
     kubectl port-forward svc/{{ include "comuki.fullname" . }} 8080:{{ .Values.service.port }}
  {{- end }}

3. Log in with the bootstrap admin: {{ .Values.bootstrapAdmin.email }}
   (password from secrets.bootstrapAdminPassword / your Secret).

4. Workers run as {{ if eq .Values.compute.provider "kubernetes" }}batch/v1 Jobs in namespace "{{ include "comuki.workerNamespace" . }}" (image {{ .Values.compute.workerImage }}){{ else }}Docker containers via the Docker compute provider{{ end }} — they are started
   automatically when work is queued; nothing to deploy by hand.

Notes:
  - The host Deployment is pinned to replicas=1 (in-memory worker-token
    store + SignalR connection map). Do not scale it horizontally.
  - {{ if eq .Values.compute.provider "kubernetes" }}The host's ServiceAccount "{{ include "comuki.serviceAccountName" . }}" can create worker Jobs (Role "{{ include "comuki.fullname" . }}-worker-spawn").{{ else }}Compute provider is "docker" — unusual in Kubernetes; the host needs access to a Docker daemon socket.{{ end }}

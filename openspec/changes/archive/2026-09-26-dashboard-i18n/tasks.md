# Dashboard i18n — Tasks

Order: infrastructure → projects (pattern reference) → shell/auth/home →
duty screens → management flows → long-tail domains → shared kit + helpers
→ enforcement flip. Every wave ends with the full FE gate:
`cd dashboard && bun run typecheck && bun run lint && bun run test && bun run build`.
No backend work. Never run `bun run dev` / watch processes from the agent.
Per wave: EN keys are authored and reviewed first; `ru` values land the
same wave owner-reviewed; the six draft locales (de, es, fr, pt-BR,
zh-CN, ja) are machine-generated from the wave's EN catalogue (design
D13/D14).
